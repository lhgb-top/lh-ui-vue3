Add four new components: LhTag (labels with closable support), LhBadge (count/dot badges, fixed to apply styles through the `lh-badge__content` element on the root container), LhCascader (multi-level cascading selection with search), and LhTimePicker (time selection with stepping). Each ships with core pure logic, unit and component tests, and a docs page.
