Roll out the `sx` quick-layout prop across the four high-frequency components: `LhButton`, `LhInput`, `LhDialog`, and `LhTooltip`. The prop accepts Tailwind-style shorthand (`mt`, `px`, `flex`, …) scaled on an 8px base and compiles to inline styles on the component root element, so common spacing and sizing tweaks no longer need a wrapping element or custom CSS.
