Add four data-display components (Stage 2 of the roadmap): LhAvatar (image/icon/text avatars with error fallback), LhProgress (line and circle progress with status, custom color and format), LhStatistic (numeric display with precision, grouping, prefix/suffix), and LhDescriptions (label/value lists with column span and border mode). Each ships with core pure logic, unit and component tests, a docs page, and a playground demo.
