## 一、目标与原则

### 1.1 目标

当前组件库 22 个组件，结构失衡：**导航类 0、布局类 0、反馈类仅 Dialog/Tooltip、无命令式全局反馈、无媒体与大数据组件**。本计划按六批（Wave）扩充约 30 个组件，把组件库补到覆盖中后台系统日常开发的完整面。

### 1.2 原创性声明（重要）

本计划的组件设计**只综合吸收各开源库共同验证过的交互模式与 WAI-ARIA 用法**，作为「这类组件应该怎么工作」的行业共识参考；**命名、代码实现、视觉语言、API 组织全部原创**，遵守本仓库既有约定（BEM `lh-*` 命名、core 纯函数分层、CSS 变量主题、`sx` 快速布局）。

- 参考对象限于公认成熟库的**通行做法**：Element Plus、Ant Design、Naive UI、Radix Vue、PrimeVue、Vuetify、Headless UI。
- **不复制**任何库的源码、独有 API 命名或视觉细节；每个组件卡在「参考共性」一栏说明综合了哪些库的通行做法，便于溯源。
- 同一交互如果各库做法分歧，以 **WAI-ARIA Authoring Practices（APG）** 为准绳裁决。

### 1.3 三支柱：每个组件的验收硬门槛

| 支柱 | 要求 |
| --- | --- |
| **国际化** | ① 用户可见文案进 `packages/locales/lang/`，**6 份语言文件同步**（zh-CN 真实翻译，其余英文兜底）；② 组件内用响应式 `t()` 封装（`void lhlocale.version.value` 建立依赖）；③ 文案可被插槽覆盖（沿用 Select `empty` / Cascader `no-match` 模式）；④ core 层不放文案（沿用 Cascader/DatePicker 占位符分层修正的约定） |
| **无障碍** | ① 对齐 WAI-ARIA APG 对应 pattern（role、aria-* 状态、键盘行为表）；② 焦点管理可测（`:focus-visible` 样式、焦点顺序、焦点圈/归还）；③ 尊重 `prefers-reduced-motion` 与 `prefers-contrast`；④ 图形性内容有文本替代；⑤ 组件测试含 a11y 断言（role/aria 属性/键盘触发） |
| **现代浏览器规范** | ① 语义化标签优先（`nav`/`ol`/`section`/`details`…）；② 主题全部走 CSS 自定义属性（不新增硬编码色值）；③ 适度使用平台能力：`:focus-visible`、`color-mix()`、`ResizeObserver`、`IntersectionObserver`、`scrollend`，按需评估 Popover API 与原生 `<dialog>`；④ **渐进增强**——新特性只做增强、必须有回退，不抬高 browserslist 基线 |

三支柱写入每张组件卡，落地时按 §五 的 10 步清单验收。

## 二、现状缺口分析

### 2.1 分类覆盖现状（22 组件）

| 分类 | 已有 | 缺口 |
| --- | --- | --- |
| 基础 | Button、Icon | — |
| 表单 | Input、InputNumber、Select、Checkbox、Radio、Switch、Slider、DatePicker、TimePicker、Cascader、Form | 评分、分段选择、穿梭、上传、树选择、自动补全 |
| 数据展示 | Tag、Badge、Avatar、Progress、Statistic、Descriptions | 表格、树、时间线、折叠、图片、日历、列表虚拟化 |
| 反馈 | Dialog、Tooltip | 轻提示、通知、警告、加载、骨架屏、空状态、结果页、气泡确认、抽屉 |
| 导航 | **0** | 面包屑、分页、标签页、步骤条、下拉菜单、锚点、菜单 |

| 其他 | ConfigProvider | 固定钉、返回顶部、水印 |

### 2.2 存量无障碍债务

**初始基线（2026-09-15）**：当时 `packages/components` 23 个组件中仅 **5 个**（checkbox、dialog、radio、select、switch）使用了 aria-*。此后按 §五.3 的债务清单分批补齐：第十轮（Button、Tooltip）、第十五轮（Form/Progress/Statistic/Tag/Badge/Avatar/Descriptions）、第十六轮（focus-trap 焦点圈枚举）、第十七轮（十控件 aria-invalid），存量 a11y 债务仅剩「DatePicker/TimePicker/Cascader 面板键盘化」排 Wave E 后专项。

### 2.3 语言包与 a11y 的交叉

`message` 语言组已定义但无消费（死键）——本计划 Wave D 的 Message 组件落地时直接激活；各新组件的语言键组沿用现有 16 组命名风格新增（`breadcrumb`、`pagination`、`tabs`、`upload`…）。

## 三、推荐组件总表（六批 Wave）

推进顺序综合考虑：**铺量优先**（低复杂度组件快速提升覆盖面）、**依赖就绪**（被依赖者先行）、**风险隔离**（重型组件单独排期）。

| 批次 | 主题 | 组件 | 复杂度 | 关键依赖/备注 |
| --- | --- | --- | --- | --- |
| **Wave A** | 布局 + 反馈基础（快速铺量） | Divider、Space、Card、Empty、Skeleton、Alert | 低 | Card 兼任 `sx` 第 5 个高频组件；Alert 落地 `role=alert`；Empty/Skeleton 为 Table/Upload 等后续组件的加载与空态基座 |
| **Wave B** | 导航骨架 | Breadcrumb、Pagination、Tabs、Steps | 中 | Breadcrumb 用 `nav + ol` 语义；Tabs 严格对齐 APG tabs pattern（roving tabindex）；Pagination 激活新语言组 |
| **Wave C** | 覆盖层 | Popover、Popconfirm、Drawer、Dropdown | 中高 | 复用 Tooltip 的定位与 teleport 经验（抽共享 `useLhPopper`）；Drawer 评估原生 `<dialog>` + 焦点圈；Dropdown 对齐 APG menu pattern，为 Menu 铺路 |
| **Wave D** | 命令式全局反馈 | Message、Notification、Loading（服务 + 指令） | 中 | 服务式 API（`LhMessage.success(...)`）全局挂载；live region（`role=status` / `aria-live`）；激活 `message` 死键组 |
| **Wave E** | 数据与媒体增强 | Image（含预览）、Timeline、Collapse、Rate、Segmented、Calendar、Affix、BackTop | 中 | Segmented/Rate 补表单空档；Calendar 复用 DatePicker core；Affix/BackTop 用 `IntersectionObserver` |
| **Wave F** | 重型组件（专项设计，单个迭代） | Table（虚拟滚动）、Tree、TreeSelect、Transfer、Upload、Menu、Layout + Grid(Row/Col) + Container、Anchor、VirtualList | 高 | Table/Tree/VirtualList 用 `ResizeObserver` 窗口化渲染；Menu 依赖 Dropdown；Upload 激活新语言组并含 a11y 焦点方案 |

**明确不做**（避免范围蔓延，登记理由）：
- **Watermark**：canvas 方案与暗色/花纹主题叠加效果差，需求罕见；不排期。
- **Carousel**：轮播在管理后台场景使用率低，动效成本高；如有需求再议。
- **CascaderPanel（独立面板）**：现有 Cascader 已含面板，拆分收益低。
- **Autocomplete**：Select 的 `filterable` + 自定义插槽可覆盖大部分场景；待真实需求验证。
- **Tour / Intro 引导**：与组件库定位不符。

## 四、组件卡（分批详细设计）

> 卡片字段：功能边界 / API 草案 / i18n 键 / ARIA 与键盘 / 现代特性 / 主题与 sx / 测试要点 / 参考共性。
> API 草案为**命名原创**的提案，实现时可微调，但三支柱字段不可裁剪。

### Wave A

#### A1. Divider 分割线

- **功能边界**：水平/垂直分割线；可带文案（居左/中/右）；纯展示无交互。
- **API 草案**：props `direction?: 'horizontal' | 'vertical'`、`labelPosition?: 'left' | 'center' | 'right'`、`dashed?: boolean`、`borderStyle?: string`；slot `default`（文案）。
- **i18n**：无文案键（纯展示）。
- **ARIA 与键盘**：装饰性分割 `role="presentation"` 不进无障碍树；带文案时用 `role="separator"`（垂直时 `aria-orientation="vertical"`）；键盘不可聚焦。
- **现代特性**：伪元素绘制，`border-block-start` 等逻辑属性。
- **主题与 sx**：颜色走 `--lh-border-color`；接入 `sx`。
- **测试要点**：方向/虚线类名、带文案渲染、`role="separator"` 断言。
- **参考共性**：综合 Element Plus / Ant Design / Naive UI 的「带文案分割线」通行交互；`lh-divider` 命名与实现原创。

#### A2. Space 间距

- **功能边界**：为子元素提供统一间距（水平/垂直/换行包裹），替代手写 gap 布局。
- **API 草案**：props `direction?: 'horizontal' | 'vertical'`、`size?: 'small' | 'medium' | 'large' | number | [h, v]`、`wrap?: boolean`、`alignment?: 'start' | 'center' | 'end' | 'baseline'`。
- **i18n**：无文案键。
- **ARIA 与键盘**：`role="presentation"`（纯布局容器）或默认不设 role；不拦截焦点。
- **现代特性**：内部实现优先 CSS `gap`（flex/grid 原生能力），`size` 为数字时内联样式覆盖。
- **主题与 sx**：间距 token `--lh-spacing-*` 映射三档；接入 `sx`。
- **测试要点**：三档类名与内联 gap、direction/wrap、多子元素间距一致性。
- **参考共性**：综合 Ant Design / Element Plus / Naive UI 的 Space 通行语义；实现走原生 gap（部分库用 margin 遍历，本库不采用）。

#### A3. Card 卡片

- **功能边界**：内容容器（头部/主体/底部/封面四区）；可整体可点击；阴影三档。
- **API 草案**：props `title?: string`、`shadow?: 'always' | 'hover' | 'never'`、`clickable?: boolean`、`loading?: boolean`（占位 Skeleton）；slots `header`、`default`、`footer`、`cover`、`extra`。
- **i18n**：无文案键（loading 态用 aria-label 键 `card.loading`）。
- **ARIA 与键盘**：`clickable` 时渲染为整卡可聚焦（`tabindex="0"` + `role="button"` 或内嵌交互元素），Enter/Space 触发并 `emit('click')`；loading 时容器 `aria-busy="true"`。
- **现代特性**：`color-mix()` 派生 hover 阴影层次；`:focus-visible` 焦点环。
- **主题与 sx**：`--lh-card-*` 变量族（bg/border/radius/padding）；**`sx` 第 5 个高频组件**（补齐 `ai/pt-sx-research.md` 清单）；`bg-pattern` 白名单可选接入。
- **测试要点**：四区渲染、shadow 类名、clickable 键盘触发、loading 联动。
- **参考共性**：综合 Element Plus / Ant Design / Naive UI 的卡片分区通行结构；可点击卡的键盘方案按 APG button pattern。

#### A4. Empty 空状态

- **功能边界**：空数据占位（图标 + 文案 + 动作区）；自定义图片。
- **API 草案**：props `description?: string`、`image?: string`；slots `default`（自定义图）、`description`、`actions`。
- **i18n**：新组 `empty: { description: '暂无数据' }`（en: 'No data'），6 文件同步；`description` slot 覆盖。
- **ARIA 与键盘**：容器 `role="status"`（屏读自动播报空态）；纯装饰图片 `alt=""`。
- **现代特性**：SVG 内联插画（主题变量着色，跟随明暗模式）。
- **主题与 sx**：`--lh-empty-*`；接入 `sx`。
- **测试要点**：默认/自定义文案、slot 覆盖、`role="status"` 断言。
- **参考共性**：综合 Ant Design / Element Plus / Naive UI 的空态通行结构；插画原创。

#### A5. Skeleton 骨架屏

- **功能边界**：加载占位（文本行/圆形头像/矩形块/段落），可组合；`loading` 切换真实内容。
- **API 草案**：`LhSkeleton` props `loading?: boolean`、`rows?: number`、`avatar?: boolean`、`animated?: boolean`；slot `default`（loading=false 时的真实内容）。`LhSkeletonItem` props `variant?: 'text' | 'rect' | 'circle'`。
- **i18n**：无文案键。
- **ARIA 与键盘**：容器 `aria-busy="true"` + `aria-live="polite"`（加载完成后播报）；占位块 `aria-hidden="true"`。
- **现代特性**：动效走 CSS `@keyframes`，包裹 `@media (prefers-reduced-motion: reduce)` 关闭动画。
- **主题与 sx**：`--lh-skeleton-*`；接入 `sx`。
- **测试要点**：loading 切换渲染、rows/avatar、动画类名、`aria-busy` 断言。
- **参考共性**：综合 Element Plus / Ant Design / Naive UI 的骨架屏组合方式；动画降级为本库强约束（多数库未处理 reduced-motion）。

#### A6. Alert 警告提示

- **功能边界**：页面级静态警告（非命令式）；四语义色 + 可关闭 + 可带图标/标题/描述。
- **API 草案**：props `type?: 'info' | 'success' | 'warning' | 'danger'`、`title?: string`、`closable?: boolean`、`showIcon?: boolean`、`plain?: boolean`；emits `close`；slots `default`（描述）、`title`、`icon`。
- **i18n**：新组 `alert: { close: '关闭警告' }`（en: 'Dismiss alert'，作关闭按钮 aria-label）。
- **ARIA 与键盘**：**`role="alert"`**（error/danger 场景屏读立即播报）或 `role="status"`（info/success 温和播报，实现按 type 映射）；关闭按钮真实 `<button>` + aria-label；Esc 不关闭（静态展示，区别于 Dialog）。
- **现代特性**：语义色用 `color-mix()` 从 `--lh-*-color` 派生浅底；`:focus-visible`。
- **主题与 sx**：`--lh-alert-*`；`bg-pattern` 不接入（警示区不宜花纹）；接入 `sx`。
- **测试要点**：四 type 类名、closable 事件、`role` 按 type 映射、关闭按钮 aria-label。
- **参考共性**：综合 Element Plus / Ant Design / Naive UI 的四语义 Alert 通行结构；role 映射方案为本库按 APG 细化。

### Wave B

#### B1. Breadcrumb 面包屑

- **功能边界**：层级路径导航；当前页不可点；可自定义分隔符；折叠过多层级。
- **API 草案**：`LhBreadcrumb` props `separator?: string`、`maxItems?: number`（超出折叠为省略下拉）；`LhBreadcrumbItem` props `to?: string`（vue-router 或原生 href）、`replace?: boolean`；slot `separator`。
- **i18n**：新组 `breadcrumb: { more: '更多' }`（折叠项 aria-label，en: 'More'）。
- **ARIA 与键盘**：`<nav aria-label="面包屑">` 包 `<ol>`（语义顺序）；当前页 `aria-current="page"`；折叠省略项可聚焦展开。
- **现代特性**：原生 `nav + ol` 语义（不造列表结构）；`to` 支持原生 `<a>` 渲染。
- **主题与 sx**：`--lh-breadcrumb-*`；接入 `sx`。
- **测试要点**：ol/li 结构、`aria-current`、折叠 maxItems、`to` 渲染为链接。
- **参考共性**：综合 Element Plus / Ant Design 的折叠与分隔符通行交互；语义结构按 APG breadcrumb pattern。

#### B2. Pagination 分页

- **功能边界**：页码导航（上一页/页码/下一页/省略/条数选择/跳页/总数）。
- **API 草案**：props `total: number`、`pageSize?: number`、`current?: number`（v-model:current）、`pageSizes?: number[]`、`showJumper?: boolean`、`showSizeChanger?: boolean`、`showTotal?: boolean`、`simple?: boolean`、`disabled?: boolean`；emits `change`、`size-change`。
- **i18n**：新组 `pagination: { total: '共 {total} 条', prev: '上一页', next: '下一页', page: '第 {page} 页', goto: '前往', sizeChanger: '{size} 条/页' }` 等，6 文件同步；页码 aria-label 键。
- **ARIA 与键盘**：`<nav aria-label="分页导航">`；页码列表 `role="list"`；当前页 `aria-current="page"`；按钮组每项有独立 aria-label（纯「<」图标按钮必须命名）；跳页输入框带 `<label>`；方向键不跨页（Enter 触发）。
- **现代特性**：省略逻辑在 core 纯函数（可单测穷举）；数字按钮 `:focus-visible`。
- **主题与 sx**：`--lh-pagination-*`；接入 `sx`。
- **测试要点**：core 省略算法（连续页码窗口收缩）、v-model、size-change、`aria-current` 与按钮命名断言。
- **参考共性**：综合 Element Plus / Ant Design / Naive UI 的页码窗口算法通行做法（各库算法一致，本库 core 独立实现）。

#### B3. Tabs 标签页

- **功能边界**：同层内容切换；线条/卡片两种外观；可增删（editable）；可禁用单页。
- **API 草案**：`LhTabs` props `modelValue?: string`（v-model）、`type?: 'line' | 'card'`、`closable?: boolean`、`addable?: boolean`、`tabPosition?: 'top' | 'bottom'`；emits `tab-change`、`tab-remove`、`tab-add`；`LhTabPane` props `name: string`、`label?: string`、`disabled?: boolean`；slots `label`、`default`。
- **i18n**：新组 `tabs: { close: '关闭标签页 {name}', add: '新增标签页' }`（关闭/新增按钮 aria-label）。
- **ARIA 与键盘**：**严格对齐 APG tabs pattern**——tab 列表 `role="tablist"`、每页签 `role="tab"` + `aria-selected` + `aria-controls`、面板 `role="tabpanel"` + `aria-labelledby` + `tabindex="0"`；**roving tabindex**（仅激活 tab 可聚焦）；方向键移动、Home/End 首尾、Delete 关闭（closable 时）。
- **现代特性**：指示条用 CSS 变量过渡（不测量 DOM 的 hacks）；`scrollend` 事件驱动横向滚动箭头显隐（回退 scroll 监听）。
- **主题与 sx**：`--lh-tabs-*`；接入 `sx`。
- **测试要点**：tablist/tab/tabpanel 三 role 关联断言、方向键 roving、v-model、closable 事件、禁用页不可激活。
- **参考共性**：APG tabs pattern 为唯一键盘准绳（各库键盘实现参差，本库按 APG 全量实现）。

#### B4. Steps 步骤条

- **功能边界**：流程步骤指示（水平/垂直）；当前/完成/等待/错误四态；可点击导航（可选）。
- **API 草案**：`LhSteps` props `current: number`（v-model）、`direction?: 'horizontal' | 'vertical'`、`clickable?: boolean`、`status?: 'wait' | 'process' | 'finish' | 'error'`（整体覆盖）；`LhStep` props `title?: string`、`description?: string`、`icon?: string`；emits `change`。
- **i18n**：新组 `steps: { step: '第 {index} 步', finish: '已完成', error: '出错' }`（aria-label 用）。

#### F2. Tree 树形控件
- 方向：扁平数据 → 树的 core 纯函数转换；勾选/展开/懒加载/受控模式分阶段。
- a11y：`role="tree"`/`treeitem`/`group` + `aria-expanded`/`aria-selected`/`aria-level`；方向键树导航（APG tree pattern：上下移动、左右展开收起）。
- i18n：`tree: { expand, collapse, selectAll ... }`。
- 参考共性：综合各库树交互通行状态机；键盘按 APG 全量实现。

#### F3. TreeSelect 树选择
- 方向：Select 触发器 + Tree 面板组合；单选/多选/勾选策略。
- 依赖：Select、Tree、popper 引擎。
- a11y：combobox + tree 组合 pattern（`aria-haspopup="tree"`）。

#### F4. Transfer 穿梭框
- 方向：双栏列表 + 勾选移动；数据源在 core 层做不可变分区（left/right/checked）。
- a11y：双 listbox + 操作按钮命名 + 键盘全流程（APG listbox pattern）。
- i18n：`transfer: { sourceTitle, targetTitle, moveRight, moveLeft ... }`。

#### F5. Upload 上传
- 方向：原生 `<input type="file">` 驱动 + 拖拽区；手动/自动上传、进度、 fileList 受控；上传逻辑在 core（XMLHttpRequest，零依赖）。
- a11y：input 关联 label、拖拽区键盘可达（Enter/Space 打开文件选择）、进度条 `role="progressbar"` + `aria-valuenow`。
- i18n：`upload: { select, drag, remove, retry, exceed ... }`。
- 现代特性：`File System Access API` 评估（渐进增强）；拖拽用原生 DnD 事件。

#### F6. Menu 导航菜单
- 方向：垂直/水平多级菜单；路由集成可选；基于 Dropdown + popper 引擎。
- a11y：APG menu/navigation pattern（水平用 `menubar`、垂直用 `menu`，`aria-haspopup` 处理子级）。
- 依赖：Dropdown（Wave C）、Icon。

#### F7. Layout / Grid(Row,Col) / Container 布局容器
- 方向：Layout（aside/header/main/footer 语义标签）+ 24 栅格 Grid。
- 现代特性：**栅格优先 CSS Grid**（`grid-template-columns: repeat(24, 1fr)` + span），flex 回退；语义化 `<aside>/<header>/<main>/<footer>`。
- a11y：landmark role 由语义标签天然获得；Layout 的 `<aside>` 支持 `aria-label`。
- 参考共性：24 栅格为行业共识；CSS Grid 实现优于各库的 flex 百分比方案（现代浏览器已普及）。

#### F8. Anchor 锚点
- 方向：页面内锚点导航 + 滚动联动高亮。
- 现代特性：`IntersectionObserver` 联动（替代 scroll 计算）；`scrollend`。
- a11y：`<nav>` 语义 + `aria-current="location"`。

#### F9. VirtualList 虚拟列表
- 方向：通用窗口化列表（定高/动高两阶段）；为 Table/Tree 提供基座。
- 现代特性：`ResizeObserver` 动高测量 + core 纯函数区间计算；`content-visibility: auto` 评估。
- 参考共性：窗口化算法为通用技术（各虚拟滚动库算法同源），本库 core 独立实现。

### 5.4 现代特性使用原则

- **渐进增强**：新 API（`<dialog>`、`inert`、`scrollend`、Anchor Positioning、Popover API）只做增强分支，必须有可用的回退实现；不抬高 browserslist 基线。
- **零运行时依赖**：定位、虚拟滚动、焦点管理自研，不引入 Popper/虚拟列表等第三方运行时库。
- **性能优先**：能用 `IntersectionObserver`/`ResizeObserver` 不用 scroll/resize 监听 + 节流；能用原生 CSS（`gap`、`:focus-visible`、`color-mix()`、grid 过渡）不写 JS。
