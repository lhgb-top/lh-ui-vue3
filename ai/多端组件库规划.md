## 三、各仓库职责与红线

| 仓库 | npm 包 | 职责 | 依赖 |
| --- | --- | --- | --- |
| lh-ui-plus | lh-ui-plus（现有名不变） | Vue3 库（现状保留） | — |
| lh-ui-share | `@lh-ui/share` | core 纯函数 / theme / constants / locales / types / utils / **样式源** / core 单测 | 零依赖 |
| lh-ui-vue2 | `@lh-ui/vue2` | Vue 2.7 SFC + composables + locale 适配 + install/命令式服务 + docs | `@lh-ui/share`（唯一）+ peer vue@^2.7.0 |
| lh-ui-react | `@lh-ui/react` | React tsx + context/hooks + locale 适配 + imperative 服务 + docs | `@lh-ui/share`（唯一）+ peer react 18/19 |
| lh-ui-uniapp | `@lh-ui/uniapp` | easycom SFC 源码 + uni-adapter + docs（发源码） | `@lh-ui/share`（唯一） |

**红线（写入各仓库 AGENTS.md）**：

1. **依赖方向唯一**：UI 库 → `@lh-ui/share`；UI 库之间零依赖、禁止跨库 import；share 不依赖任何 UI 库与任何框架。
2. **share 纯度**：`lh-ui-share/src` 内禁止 `import 'vue'/'react'/'@dcloudio/*'`（CI grep 门禁）；一切响应式接线（ref/hooks/适配器）只在 UI 库。
3. **样式源唯一**：组件 BEM 样式只存在于 `lh-ui-share/styles/`；UI 库只做编译（含 uniapp 的 px→rpx 转译），禁止手写/拷贝修改组件样式。
4. **core 单测唯一一份**（share 仓库）；UI 库只测 UI 层（组件测试 + registry 测试 + 适配层测试）。
5. **发布顺序硬约束**：share 先发版，UI 库随其后（`dependencies` 语义版本已发布才可发）。

## 四、@lh-ui/share 设计要点

详见 `ai/share包计划.md`。要点：

- **提取清单**（从 lh-ui-plus 一次性提取，`extract-from-plus.mjs`）：`packages/core/**` → `src/core/**`；`packages/theme/**` → `src/theme/**`；constants / locales / types / 纯 utils；`packages/components/*/style/index.scss` → `styles/<name>/index.scss`；`tests/unit/core/**` 原样迁移。
- **exports 子路径**（对齐 plus 的 `@lh-ui/core/<name>` 惯例）：`.`、`./core/*`、`./constants`、`./locales`、`./theme`、`./types`、`./utils`、`./theme.css`、`./theme-dark.css`、`./styles/*`（scss 源）、`./styles.css`。
- **LhLocale 去响应式**（关键改造）：`version = ref(0)` → 纯事件发射器（`version` 数字 + `subscribe()`）；vue2/uniapp 适配层 ref 包装恢复 `void lhlocale.version.value` 惯用法，react 用 `useSyncExternalStore`。
- **BEM 工具还原为纯函数**：`useLhNamespace` → `createNamespace`（它本就是纯字符串函数），进 `share/src/utils/namespace.ts`。
- **样式源规范**：过渡类名双写（`-enter` 与 `-enter-from` 并列，一份源服务三框架）；hairline 标记（`/* hairline */`）供 uniapp rpx 转译跳过。

## 五、共享样式策略（企业级主流参照）

| 参照库 | 做法 | 取舍 |
| --- | --- | --- |
| **TDesign**（腾讯，跨 vue2/vue3/react/小程序） | `tdesign-common` 共享仓持**唯一样式源**，各框架包构建时编译进自己的 dist；类名 `t-*` 全家族一致 | **采用**——与 lh-ui 场景最同构 |
| **Prime**（PrimeReact/PrimeVue/PrimeNG） | `@primeuix/themes` 共享主题包被三框架共同消费 | 参照其「主题/令牌共享」思路 |
| **Ant Design Vue** | 转译 antd 样式随包发布（源共享、产物入包） | 印证「产物随库」 |

**定案：源唯一在 share，产物随各库发布。**

1. vue2/react 构建时从 `@lh-ui/share/styles/<name>` 编译出各自包内的 `es/<name>/style/index.css`，并把 theme.css 一并编译进 dist——**用户单包自足，接入方式与 plus 完全一致**；share 同时发布自己的编译产物（`./styles.css`、`./theme.css`，独立使用场景）。
2. **过渡类名双写**：同一份源并列写 `.lh-x-enter`（Vue2）与 `.lh-x-enter-from`（Vue3/React），互不冲突。
3. **uniapp**：同一 px 基准源 → 构建期 postcss 插件 px→rpx（750 基准）→ 生成 `components/<name>/style.scss` 产物入包（使用方零配置）；`/* hairline */` 标记跳过转换；`page` 选择器变体（var-uni.scss）只做包装、令牌值唯一在 share。
4. 三库 BEM 类名完全一致（`lh-*`），保证跨库视觉一致与文档对照。

## 六、依赖与发布机制

- **dependencies vs peerDependencies**：`@lh-ui/share` 是各库的 `dependencies`（运行时必需，随装随用）；框架（vue/react）是 `peerDependencies`（宿主提供，不重装）。
- **本地联调**：UI 库执行 `pnpm link ../lh-ui-share`（同父目录平级布局天然支持）；联调结束 `pnpm unlink` 恢复 npm 版本。
- **版本策略**：各仓库独立 changesets（`access: "public"`）、独立版本、0.x 起步、不锁步；share 升级后各库 `pnpm up @lh-ui/share` + 回归再发各自版本。
- **CI**：每仓库独立 workflow——share：lint → typecheck → test(core) → build → verify-dts；UI 库：lint → typecheck → test(组件/registry/适配) → build → docs:build。
- **零依赖红线修订**：各库唯一允许的运行时依赖是 `@lh-ui/share`；其余红线不变（不引 classnames/portal-vue/floating-ui/uni-ui 等）。
