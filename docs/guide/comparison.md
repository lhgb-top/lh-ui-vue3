# 组件库对比

lh-ui-plus 与其他主流 Vue UI 库的对比分析。

## 核心对比

| 特性 | lh-ui-plus | Element Plus | Ant Design Vue | Naive UI |
|------|-----------|-------------|----------------|----------|
| 样式语言 | CSS 变量 | SCSS 变量 | CSS 变量（Less token） | CSS 变量 |
| 暗色模式 | ✅ | ✅ | ✅（主题 token） | ✅ |
| 花纹背景 | ✅ 6 种 | ❌ | ❌ | ❌ |
| 跨框架 | ✅ 纯函数逻辑 | ❌ | ❌ | ❌ |
| 国际化 | ✅ zh/en 完整，其余语言包占位 | ✅ | ✅ | ✅ |
| sx 布局 | ✅ | ❌ | ❌ | ❌ |
| PassThrough | ❌ | ❌ | ❌ | ❌（主题覆写） |
| BEM 命名 | `lh-` | `el-` | `ant-` | `n-` |

## 独有优势

1. **国风设计体系** — 基于中国传统颜料的配色方案
2. **CSS 变量主题 (88+ token)** — 比 SCSS 更新灵活
3. **跨框架** — 纯函数逻辑，未来可适配 React
4. **花纹背景系统** — 传统 SVG 纹背景
5. **sx 快速布局** — 类似 Tailwind 的原子化内联样式

## 选择建议

- 需要 **国风设计 / 花纹背景** → lh-ui-plus
- 需要 **暗色模式** → 四者皆可
- 需要 **跨框架支持** → lh-ui-plus（组件逻辑与框架解耦）
- 需要 **完整生态与企业级表单** → Element Plus / Ant Design Vue
- 需要 **主题深度覆写** → Naive UI（theme overrides）
