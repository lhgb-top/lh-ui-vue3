# Timeline

Vertical event flow. Semantic `<ol>` list where document order equals time order.

## Alternate layout and hollow dots

`mode="alternate"` places items on both sides of the axis; `hollow` renders a dot as a hollow circle, typically for pending states.

<DemoBlock title="Alternate">
  <LhTimeline mode="alternate">
    <LhTimelineItem timestamp="Q1">Planning</LhTimelineItem>
    <LhTimelineItem timestamp="Q2">Development</LhTimelineItem>
    <LhTimelineItem timestamp="Q3" type="danger">Load testing</LhTimelineItem>
  </LhTimeline>
</DemoBlock>

<DemoBlock title="Hollow">
  <LhTimeline>
    <LhTimelineItem timestamp="Q1" hollow>Not started</LhTimelineItem>
    <LhTimelineItem timestamp="Q2">In progress</LhTimelineItem>
    <LhTimelineItem timestamp="Q3" type="success">Done</LhTimelineItem>

## API

### LhTimeline Props

| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| mode | Layout mode | `"left" \| "alternate"` | `'left'` |
| sx | Quick layout props | `SxProps` | — |

### LhTimelineItem Props

| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| timestamp | Timestamp | `string` | — |
| type | Node semantic type | `'primary' \| 'success' \| 'warning' \| 'danger'` | — |
| hollow | Hollow dot | `boolean` | `false` |
| sx | Quick layout props | `SxProps` | — |

Slots: `default`, `timestamp`, `dot`.

## Accessibility

- Semantic `<ol>`; screen readers announce items in time order
- Dots are decorative (`aria-hidden="true"`)
