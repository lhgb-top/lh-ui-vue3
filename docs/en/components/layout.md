## Direction

`direction` controls how children are laid out: `horizontal` side by side (default) or `vertical` stacked. The direction switches to `vertical` automatically when an `LhLayoutAside` is present.

## API

### LhLayout Props

| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| direction | Direction (auto vertical when an Aside is present) | `"horizontal" \| "vertical"` | `'horizontal'` |
| sx | Quick layout props | `SxProps` | — |

### LhLayoutAside Props

| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| width | Aside width | `number \| string` | — |
| ariaLabel | Accessible name (landmark labelling) | `string` | — |
| sx | Quick layout props | `SxProps` | — |

Header / Main / Footer take only `sx`.

## Accessibility

- Semantic tags map directly to landmark roles
- When multiple asides exist, label them with `ariaLabel`
