## Controlled v-model and disabled items

`v-model` controls the open panel(s) (single value or array depending on accordion mode); `disabled` disables an individual panel.

<DemoBlock title="Controlled">
  <LhCollapse v-model="activeNames">
    <LhCollapseItem name="a" title="Panel A">Controlled content A</LhCollapseItem>
    <LhCollapseItem name="b" title="Panel B (disabled)" disabled>Disabled content</LhCollapseItem>
    <LhCollapseItem name="c" title="Panel C">Controlled content C</LhCollapseItem>
  </LhCollapse>
</DemoBlock>

```vue composition
<script setup>
import { ref } from 'vue'

const activeNames = ref(['a'])
</script>

<template>
  <LhCollapse v-model="activeNames">
    <LhCollapseItem name="a" title="Panel A">Controlled content A</LhCollapseItem>
    <LhCollapseItem name="b" title="Panel B (disabled)" disabled>Disabled content</LhCollapseItem>
    <LhCollapseItem name="c" title="Panel C">Controlled content C</LhCollapseItem>
  </LhCollapse>
</template>
```

```vue options
<script>
export default {
  data() {
    return { activeNames: ['a'] }
  },
}
</script>

<template>
  <LhCollapse v-model="activeNames">
    <LhCollapseItem name="a" title="Panel A">Controlled content A</LhCollapseItem>
    <LhCollapseItem name="b" title="Panel B (disabled)" disabled>Disabled content</LhCollapseItem>
    <LhCollapseItem name="c" title="Panel C">Controlled content C</LhCollapseItem>
  </LhCollapse>
</template>
```

## API

### LhCollapse Props

| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| modelValue | Active panel(s) (controlled v-model) | `LhCollapseKey \| LhCollapseKey[]` | — |
| accordion | Only one panel open at a time | `boolean` | `false` |
| sx | Quick layout props | `SxProps` | — |

### LhCollapse Events

| Event | Description | Callback |
|-------|-------------|----------|
| update:modelValue | Active panel(s) changed; emitted in controlled mode (when `modelValue` is passed, v-model) | `(value: LhCollapseKey \| LhCollapseKey[]) => void` |
| change | Active panel(s) changed; emitted in uncontrolled mode (accordion yields a single key) | `(value: LhCollapseKey \| LhCollapseKey[]) => void` |

### LhCollapseItem Props

| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| name | Unique panel key | `string \| number` | — |
| title | Title (or title slot) | `string` | — |
| disabled | Disabled | `boolean` | `false` |
| sx | Quick layout props | `SxProps` | — |

## Accessibility

- APG accordion: header is a real `<button aria-expanded aria-controls>`, content is `role="region"` + `aria-labelledby`
- Height transition uses CSS `grid-template-rows: 0fr/1fr`; respects `prefers-reduced-motion`
