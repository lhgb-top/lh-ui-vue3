# VirtualList

Renders only the items inside the visible window, in **fixed-height** or **dynamic-height** mode (the latter positions via precomputed offsets and binary search).

## Fixed height

<DemoBlock title="Fixed">
  <LhVirtualList :data="listData" :height="200" :item-height="40">
    <template #default="{ item, index }">
      <!-- Row height matches item-height: fill the wrapper and center vertically -->
      <div style="height: 100%; box-sizing: border-box; display: flex; align-items: center; padding: 0 12px">
        Row {{ index }} · {{ item }}
      </div>
    </template>
  </LhVirtualList>
</DemoBlock>

```vue composition
<script setup lang="ts">
const listData = Array.from({ length: 1000 }, (_, i) => `Item ${i + 1}`)

    <template #default="{ item, index }">{{ item }}</template>

```

## Dynamic height

`itemSize` returns each item's height (it may be driven by real measurements).

<DemoBlock title="Dynamic">
  <LhVirtualList :data="listData" :height="200" :item-size="dynamicSize">
    <template #default="{ item, index }">
      <!-- border-box keeps the rendered row height equal to the itemSize value -->
      <div :style="{ height: `${dynamicSize(index)}px`, padding: '10px 12px', boxSizing: 'border-box' }">{{ item }}</div>
    </template>
  </LhVirtualList>
</DemoBlock>

```vue composition
<script setup>
const dynamicSize = (index) => (index % 3 === 0 ? 56 : 36)
</script>

<template>
  <LhVirtualList :data="listData" :height="200" :item-size="dynamicSize">
    <template #default="{ item, index }">{{ item }}</template>
  </LhVirtualList>
</template>
```

```vue options
<script>
export default {
  data() {
    return {
      listData: Array.from({ length: 1000 }, (_, i) => `Item ${i + 1}`),
    }
  },
  methods: {
    dynamicSize(index) {
      return index % 3 === 0 ? 56 : 36
    },
  },
}
</script>

<template>
  <LhVirtualList :data="listData" :height="200" :item-size="dynamicSize">
    <template #default="{ item, index }">{{ item }}</template>
  </LhVirtualList>
</template>
```

## Overscan

`overscan` specifies how many extra rows are rendered above and below the visible window, reducing blank flashes during fast scrolling.

## API

### LhVirtualList Props

| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| data | Data source (rendering is delegated to the default slot) | `any[]` | — |
| height | Container height (number is px) | `string \| number` | — |
| itemHeight | Item height in fixed-height mode | `number` | — |
| itemSize | Dynamic mode: returns each item's height | `(index: number) => number` | — |
| overscan | Overscan item count | `number` | `LH_VIRTUAL_OVERSCAN` |
| sx | Quick layout props | `LhSxProps` | — |

Slot: `default` (scope `{ item, index }`).

## Accessibility

- The container scrolls with the keyboard; items outside the window are not in the DOM (an inherent trade-off of long lists — combine with search/filtering)
- For a full semantic grid use Table, whose virtual scrolling is likewise driven by pure core functions
