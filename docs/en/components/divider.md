# Divider

A separator line that visually divides content. With label text it carries grouping semantics (`role="separator"`); purely decorative variants are removed from the accessibility tree.

## API

### Props

| Prop | Description | Type | Default |
| ---- | ----------- | ---- | ------- |
| direction | Divider direction (labels are not rendered vertically) | `"horizontal" \| "vertical"` | `'horizontal'` |
| dashed | Dashed style | `boolean` | `false` |
| labelPosition | Label alignment | `"left" \| "center" \| "right"` | `'center'` |
| borderStyle | Border style (e.g. `'dotted'`), reserved | `string` | — |
| sx | Shorthand layout props (e.g. `{ mt: 2, w: '50%' }`), applied as inline styles on the root element | `SxProps` | — |

### Slots

| Slot | Description | Default |
| ---- | ----------- | ------- |
| default | Divider label text (horizontal only) | — |

### Accessibility

- With label: `role="separator"` — a real grouping boundary for screen readers; vertical dividers also declare `aria-orientation="vertical"`
- Decorative: `role="presentation"`, removed from the accessibility tree
- Not focusable, no keyboard interaction
