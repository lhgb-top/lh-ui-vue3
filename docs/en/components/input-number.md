# InputNumber

`LhInputNumber` creates an input field for numeric values with increment/decrement controls.

## Basic Usage

<DemoBlock title="Basic Usage">
  <LhInputNumber v-model="value" />
</DemoBlock>

```vue composition
<script setup lang="ts">
import { ref } from 'vue'
import { LhInputNumber } from '@lh-ui/vue3'

const value = ref(1)
</script>

<template>
  <LhInputNumber v-model="value" />
</template>
```

```vue options
<script>
import { LhInputNumber } from '@lh-ui/vue3'

export default {
  components: { LhInputNumber },
  data() {
    return {
      value: 1,
    }
  },
}
</script>

<template>
  <LhInputNumber v-model="value" />
</template>
```
