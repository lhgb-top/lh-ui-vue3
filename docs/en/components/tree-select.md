# TreeSelect

A dropdown trigger combined with a Tree panel. Single mode returns a `string`, multiple mode (checkboxes) returns `string[]`.

## Basic usage

<DemoBlock title="Single">
  <LhTreeSelect :data="treeData" v-model="treeValue" />
</DemoBlock>

```vue composition
<script setup>
import { ref } from 'vue'
const treeValue = ref(undefined)
const treeData = [
  { key: 'a', label: 'Frontend', children: [
    { key: 'a-1', label: 'Vue' },
    { key: 'a-2', label: 'React' },
  ] },
  { key: 'b', label: 'Backend' },
]
</script>

<template>
  <LhTreeSelect :data="treeData" v-model="treeValue" />
</template>
```

## API

### LhTreeSelect Props

| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| data | Tree data | `[LhTreeNode](#type-LhTreeNode)`[] | — |
| modelValue | Value (string for single, string[] for multiple) | `string \| string[]` | — |
| multiple | Multiple mode (checkboxes; value is the checked key array) | `boolean` | `false` |
| disabled | Disabled | `boolean` | `false` |
| placeholder | Placeholder text | `string` | — |
| teleported | Teleport the panel to body | `boolean` | `true` |
| sx | Quick layout props | `SxProps` | — |

### LhTreeSelect Events

| Event | Description | Callback |
|-------|-------------|----------|
| update:modelValue | Emitted when the value changes (use with v-model; `string` for single, `string[]` for multiple) | `(value: string \| string[] \| undefined) => void` |
| change | Emitted after the selection changes | `(value: string \| string[] \| undefined) => void` |

## Accessibility

- The trigger is a real `<button>` with `aria-haspopup="tree"` + `aria-expanded`; the panel is `role="listbox"` (`aria-multiselectable` in multiple mode)
- Inside the panel the full APG tree-pattern keyboard support is reused
- Closes on outside click or Escape, returning focus to the trigger
