## Path Display & Search

- `show-all-levels` controls whether the input shows the full path (defaults to `true`; when off only the leaf label is shown);
- `separator` customizes the level separator (the search result panel honors it too);
- `emit-path: false` binds only the leaf value to `v-model`, while the input still echoes the full path;
- `check-strictly` allows selecting nodes at any level (a click selects directly; browse children via hover expansion);
- `filterable` enables search, listing matches as full paths;
- `collapse-tags` collapses tags in multi-select mode;
- `cascading: false` disables parent-child linkage in multi-select mode;
- `item-config` aliases the node fields (e.g. building the tree from `id` / `name`), and the path echo honors it as well.

All examples below ship pre-selected values so the display differences are visible without clicking through levels: full path `Zhejiang/Hangzhou/West Lake`, leaf only `West Lake`, and `Zhejiang > Hangzhou > West Lake` with `separator=" > "`.
