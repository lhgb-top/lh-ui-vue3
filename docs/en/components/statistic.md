## Non-numeric Text

## API

### Props

| Prop | Description | Type | Default |
| --- | --- | --- | --- |
| title | Title text | `string` | — |
| value | Statistic value; as a string it can carry very large numbers or special text | `string \| number` | `0` |
| precision | Decimal precision | `number` | `0` |
| separator | Thousand separator; an empty string disables grouping | `string` | `','` |
| prefix | Value prefix, e.g. a currency symbol | `string` | — |
| suffix | Value suffix, e.g. a unit | `string` | — |
| sx | Quick layout props | `LhSxProps` | — |

### Slots

| Slot | Description |
| --- | --- |
| title | Custom title |
| prefix | Custom prefix |
| suffix | Custom suffix |
### Accessibility

- The value carries `aria-live="polite"`, so screen readers announce the new value when it changes
- Title, prefix, and suffix are plain text and read as-is
