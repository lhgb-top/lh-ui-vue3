## API

### Props

| Prop | Description | Type | Default |
| ---- | ----------- | ---- | ------- |
| description | Description text (falls back to the `empty.description` locale message when unset) | `string` | — |
| image | Custom image URL (replaces the default inline illustration) | `string` | — |
| sx | sx quick-layout properties | `LhSxProps` | — |

### Slots

| Slot | Description | Default |
| ---- | ----------- | ------- |
| default | Custom visual area (replaces the illustration) | Default ink-wash illustration |
| description | Custom description | Locale message `empty.description` |
| actions | Action area | — |

### Accessibility

- Container has `role="status"` — announced automatically when it appears
- Decorative images use `alt=""` and are hidden from screen readers; semantics are carried by the description text
