# Switch

`LhSwitch` is used for switching between two states.

## Basic Usage

<DemoBlock title="Basic Usage">

</DemoBlock>


## Internationalization

Configure the global locale pack via `LhConfigProvider`.

<DemoBlock title="Internationalization">
  <LhConfigProvider :locale="messages">
    <LhSwitch v-model="status" />
    <LhButton @click="locale = locale === 'zh-CN' ? 'en-US' : 'zh-CN'">
      Switch Language
    </LhButton>
  </LhConfigProvider>
</DemoBlock>

```vue composition
<script setup lang="ts">
import { ref, computed } from 'vue'
import { LhConfigProvider, LhSwitch, LhButton } from '@lh-ui/vue3'
import { zhCN } from '@lh-ui/vue3'
import { enUS } from '@lh-ui/vue3'

const locale = ref('zh-CN')
const messages = computed(() => locale.value === 'zh-CN' ? zhCN : enUS)
const status = ref(false)
</script>

<template>
  <!-- Locale configuration -->
  <LhConfigProvider :locale="messages">
    <LhSwitch v-model="status" />
    <LhButton @click="locale = locale === 'zh-CN' ? 'en-US' : 'zh-CN'">
      Switch Language
    </LhButton>
  </LhConfigProvider>
</template>
```

```vue options
<script>
import { LhConfigProvider, LhSwitch, LhButton } from '@lh-ui/vue3'
import { zhCN } from '@lh-ui/vue3'
import { enUS } from '@lh-ui/vue3'

export default {
  components: { LhConfigProvider, LhSwitch, LhButton },
  data() {
    return {
      locale: 'zh-CN',
      status: false,
    }
  },
  computed: {
    messages() {
      return this.locale === 'zh-CN' ? zhCN : enUS
    },
  },
}
</script>

<template>
  <!-- Locale configuration -->
  <LhConfigProvider :locale="messages">
    <LhSwitch v-model="status" />
    <LhButton @click="locale = locale === 'zh-CN' ? 'en-US' : 'zh-CN'">
      Switch Language
    </LhButton>
  </LhConfigProvider>
</template>
```

## API

### Props

| Prop | Description | Type | Default |
|------|------|------|--------|
| modelValue | Current state | `boolean` | `false` |
| disabled | Disabled | `boolean` | `false` |
| loading | Loading state | `boolean` | `false` |
| name | Native form name | `string` | `''` |
| size | Size | `"small" \| "medium" \| "large" \| "mini" \| "x-large"` | `'medium'` |
| activeText | Text when on | `string` | `''` |
| inactiveText | Text when off | `string` | `''` |
| sx | sx quick-layout props | `LhSxProps` | — |

### Events

| Event | Description | Callback |
|-------|-------------|----------|
| update:modelValue | State changed | `(value: boolean)` |
| change | State changed | `(value: boolean)` |

Emits `update:modelValue` (new boolean value) and `change` events. Supports keyboard Enter and Space to toggle.
