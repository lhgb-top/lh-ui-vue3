# Radio

`LhRadio` allows selecting a single option from a set.

## Basic Usage

<DemoBlock title="Basic Usage">
  <LhRadio v-model="selected" value="one">Option One</LhRadio>
  <LhRadio v-model="selected" value="two">Option Two</LhRadio>
  <LhRadio v-model="selected" value="three">Option Three</LhRadio>
</DemoBlock>

```vue composition
<script setup lang="ts">
import { ref } from 'vue'
import { LhRadio } from '@lh-ui/vue3'

const selected = ref('one')
</script>

<template>
  <LhRadio v-model="selected" value="one">Option One</LhRadio>
  <LhRadio v-model="selected" value="two">Option Two</LhRadio>
  <LhRadio v-model="selected" value="three">Option Three</LhRadio>
</template>
```

```vue options
<script>
import { LhRadio } from '@lh-ui/vue3'

export default {
  components: { LhRadio },
  data() {

    }

}
</script>

<template>
```
