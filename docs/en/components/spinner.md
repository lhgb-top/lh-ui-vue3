# Spinner

A basic rotating figure indicating an in-progress state. The loading mask (LhLoading) renders it internally as well.

## API

### LhSpinner Props

| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| size | Size | `"small" \| "medium" \| "large" \| "mini" \| "x-large"` | `'medium'` |
| color | Rotation color (CSS color value; inherits currentColor when unset) | `string` | — |
| sx | Quick layout props | `LhSxProps` | — |

## Accessibility

- Purely decorative: `aria-hidden="true"` removes it from the accessibility tree; the in-progress semantics belong to an outer container (e.g. `role="status"`)
- The rotation respects `prefers-reduced-motion`, degrading to a static arc
