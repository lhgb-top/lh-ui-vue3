# Icon

`LhIcon` provides built-in icons with configurable size and color.

## Basic Usage

<DemoBlock title="Basic Usage">
  <div style="display: flex; align-items: center; gap: 12px;">
    <LhIcon name="star" />
    <LhIcon name="search" />
    <LhIcon name="check" />
    <LhIcon name="close" />
  </div>
</DemoBlock>

```vue composition
<script setup lang="ts">
import { LhIcon } from '@lh-ui/vue3'
</script>

<template>
  <LhIcon name="star" />
  <LhIcon name="search" />
  <LhIcon name="check" />
  <LhIcon name="close" />
</template>
```

```vue options
<script>
import { LhIcon } from '@lh-ui/vue3'

export default {
  components: { LhIcon },
}
</script>

<template>
  <LhIcon name="star" />

</template>
```
