# TimePicker

`LhTimePicker` is used to select a specific time.

## Basic Usage

<DemoBlock title="Basic Usage">
  <LhTimePicker v-model="timeVal" placeholder="Select time" />
</DemoBlock>

```vue composition
<script setup lang="ts">
import { ref } from 'vue'
import { LhTimePicker } from '@lh-ui/vue3'

const timeVal = ref('')
</script>

<template>
  <LhTimePicker v-model="timeVal" placeholder="Select time" />
</template>
```

```vue options
<script>
import { LhTimePicker } from '@lh-ui/vue3'

export default {
  components: { LhTimePicker },
  data() {
    return {
      timeVal: '',
    }
  },

  <LhTimePicker v-model="timeVal" placeholder="Select time" />
</template>
```

## Placeholder, readonly and arrow control

`placeholder` sets the hint text; `readonly` blocks editing; `arrow-control` navigates the columns with arrow keys; `start` / `end` bound the selectable time; `step-hour` / `step-minute` / `step-second` customize column steps.
