# Rate

Star rating: read-only display, interactive scoring, half stars, custom character and count.

## Half stars, readonly and score

`allow-half` enables half-star selection; `readonly` renders a display-only rating; `show-score` shows the numeric score.

## Custom count, disabled and character

`max` changes the number of stars, `disabled` blocks interaction, and `character` replaces the star with any symbol.

<DemoBlock title="Custom">
  <div class="demo-rate-row">

    <LhRate v-model="rate4" disabled />
    <LhRate v-model="rate5" character="A" />

## API

### LhRate Props

| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| modelValue | Current value (controlled v-model) | `number` | `0` |
| max | Max stars | `number` | `5` |
| allowHalf | Allow half stars | `boolean` | `false` |
| readonly | Read-only | `boolean` | `false` |
| disabled | Disabled | `boolean` | `false` |
| character | Custom character | `string` | — |
| showScore | Show score text | `boolean` | `false` |
| scoreTemplate | Score template ({n} placeholder) | `string` | — |
| sx | Quick layout props | `LhSxProps` | — |

### LhRate Events

| Event | Description | Callback |
|-------|-------------|----------|
| update:modelValue | Emitted when the value changes (use with v-model) | `(value: number) => void` |
| change | Emitted when the value changes (by click or keyboard) | `(value: number) => void` |

## Accessibility

- Interactive mode is a `role="radiogroup"` of real focusable buttons (roving tabindex); arrows step (0.5 with half stars), Home/End to 0/max
- Read-only mode outputs `role="img"` + `aria-label="n stars"`
