# BackTop

Appears after scrolling past a threshold and scrolls back to the top on click, using the native `scrollTo({ behavior: 'smooth' })` (degrades automatically under `prefers-reduced-motion`).

## Scroll end

`@scrollend` fires with the current scroll offset when scrolling stops: the native `scrollend` event is preferred
(Chromium 114+ / Safari 18.2+); older browsers fall back to scroll + a 150ms debounce. Useful for anchor syncing and data lazy-loading.

<DemoBlock title="scrollend event">
  <div style="height: 60px" />
  <LhBackTop :right="24" :bottom="160" @scrollend="onScrollEnd" />
  <p class="demo-scrollend-log">Last stop: {{ lastStop }}</p>
</DemoBlock>

```vue composition
<script setup>
import { ref } from 'vue'

const lastStop = ref('(not scrolled)')

function onScrollEnd(scrollTop) {
  lastStop.value = `${scrollTop}px`
}
</script>

<template>
  <LhBackTop :right="24" :bottom="160" @scrollend="onScrollEnd" />
</template>
```

```vue options
<script>
export default {
  data() {
    return { lastStop: '(not scrolled)' }
  },
  methods: {
    onScrollEnd(scrollTop) {
      this.lastStop = `${scrollTop}px`
    },
  },
}
</script>

<template>
  <LhBackTop :right="24" :bottom="160" @scrollend="onScrollEnd" />
</template>
```

## API

### LhBackTop Props

| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| target | Scroll container (selector or element) | `string \| HTMLElement` | — |
| visibilityHeight | Visibility threshold in px | `number` | `200` |
| right | Right offset px | `number` | `40` |
| bottom | Bottom offset px | `number` | `40` |
| smooth | Smooth scrolling | `boolean` | `true` |
| sx | Quick layout props | `LhSxProps` | — |

### LhBackTop Events

| Event | Description | Callback |
|-------|-------------|----------|
| click | Back-to-top button clicked; scrolling back starts after the event | `(e: MouseEvent) => void` |
| scrollend | Scrolling on the target stops; carries the current scroll offset (native `scrollend` when supported, scroll + debounce otherwise) | `(scrollTop: number) => void` |

## Accessibility

- A real `<button>` named via the `backtop.label` locale key
- Hidden state is removed from the tree (`v-if`)
