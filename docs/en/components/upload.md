# Upload

Driven by a native `<input type="file">` plus a drop zone. **The request is provided by the consumer via the `request` prop** (the library has zero runtime dependencies and ships no HTTP client).

## Drag and custom request

<DemoBlock title="Drag upload">
  <LhUpload drag :multiple="true" :request="fakeRequest" />
</DemoBlock>

```vue composition
<script setup>
const fakeRequest = ({ file, onProgress }) =>
  new Promise((resolve) => {
    let percent = 0
    const timer = setInterval(() => {
      percent += 20
      onProgress(percent)
      if (percent >= 100) {
        clearInterval(timer)
        resolve({ url: `https://example.com/${file.name}` })
      }
    }, 200)
  })
</script>

<template>
  <!-- Drag upload -->
  <LhUpload drag :multiple="true" :request="fakeRequest" />
</template>
```

```vue options
<script>
export default {
  methods: {
    fakeRequest({ file, onProgress }) {

          if (percent >= 100) {
            clearInterval(timer)
            resolve({ url: `https://example.com/${file.name}` })
          }
        }, 200)
      })
    },
  },
}
</script>

<template>
  <!-- Drag upload -->
  <LhUpload drag :multiple="true" :request="fakeRequest" />
</template>
```

## API

### LhUpload Props

| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| multiple | Allow multiple selection | `boolean` | `false` |
| drag | Drop-zone mode | `boolean` | `false` |
| disabled | Disabled | `boolean` | `false` |
| accept | Allowed extensions / MIME, as an array (`['.png', 'image/*']`) or a comma-separated string (`'.png,.jpg'`) | `string \| string[]` | `() => []` |
| maxSize | Per-file size limit (bytes) | `number` | `[LH_UPLOAD_MAX_SIZE](#const-LH_UPLOAD_MAX_SIZE)` |
| maxCount | Count limit (0 = unlimited) | `number` | `0` |
| request | Upload function (local selection and validation only when omitted) | `(options: { file: File; onProgress: (percent: number) => void; }) => Promise<{ url?: string; }>` | — |
| sx | Quick layout props | `SxProps` | — |

### LhUpload Events

| Event | Description | Callback |
|-------|-------------|----------|
| change | Emitted when the file list changes (after adding, upload finished or removal) | `(files: LhUploadFile[]) => void` |
| success | Emitted when a single file uploads successfully | `(file: LhUploadFile) => void` |
| error | Emitted when a single file fails to upload | `(file: LhUploadFile, reason: string) => void` |
| remove | Emitted after a file is removed | `(uid: string) => void` |
