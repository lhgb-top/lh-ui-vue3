# Affix

Pin content to the top or bottom while scrolling. Uses IntersectionObserver (falls back to scroll listeners).

## Basic usage

<DemoBlock title="Pin to top">
  <LhAffix :offset-top="8">
    <div class="demo-affix-bar">Pinned toolbar</div>
  </LhAffix>
</DemoBlock>

`offset-bottom` pins to the bottom (takes priority over `offset-top`); `target` selects the scroll container to observe (defaults to the viewport).

<DemoBlock title="Pin to bottom">
  <LhAffix :offset-bottom="8">
    <div class="demo-affix-bar">Pinned toolbar (offset-bottom)</div>
  </LhAffix>
</DemoBlock>

## API

### LhAffix Props

| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| offsetTop | Trigger pinning when the top edge is within this px | `number` | `0` |
| offsetBottom | Trigger bottom pinning (takes precedence) | `number` | `0` |
| target | Scroll container (selector or element) | `string \| HTMLElement` | — |
| sx | Quick layout props | `LhSxProps` | — |

### LhAffix Events

| Event | Description | Callback |
|-------|-------------|----------|
| change | Emitted when the fixed state toggles (pinning on/off) | `(fixed: boolean) => void` |

## Accessibility

- No special role; the fixed state preserves the document focus order
- The placeholder keeps the layout height to avoid jumps
