# Skeleton

Placeholder preview before content loads. Placeholder blocks are `aria-hidden` from screen readers; the container signals state via `aria-busy` and `aria-live`. The pulse animation respects `prefers-reduced-motion`.

## Basic Usage

<DemoBlock title="Basic Usage">
  <LhSkeleton :rows="3" :loading="skeletonLoading" style="max-width: 420px">
    <p>Content loaded.</p>
  </LhSkeleton>
  <LhButton size="small" style="margin-top: 12px" @click="skeletonLoading = !skeletonLoading">
    {{ skeletonLoading ? 'Show content' : 'Show skeleton' }}
  </LhButton>
</DemoBlock>

```vue composition
<script setup lang="ts">
```

## Skeleton API

### Props

| Prop | Description | Type | Default |
| ---- | ----------- | ---- | ------- |
| loading | Loading state (false renders the default slot) | `boolean` | `true` |
| rows | Number of text rows | `number` | `3` |
| avatar | Include a circle avatar placeholder | `boolean` | `false` |
| animated | Enable the pulse animation | `boolean` | `true` |
| sx | sx quick-layout properties | `SxProps` | — |

### Slots

| Slot | Description |
| ---- | ----------- |
| default | Real content rendered when loading is false |

## SkeletonItem API

### Props

| Prop | Description | Type | Default |
| ---- | ----------- | ---- | ------- |
| variant | Placeholder shape | `'text' \| 'rect' \| 'circle'` | `'text'` |
| animated | Enable the pulse animation | `boolean` | `true` |
| sx | sx quick-layout properties | `SxProps` | — |

### Theme Variables

| Variable | Description | Default |
| -------- | ----------- | ------- |
| `--lh-skeleton-bg` | Placeholder base color | Ink tone (text-regular) at 10% opacity |
| `--lh-skeleton-highlight` | Shimmer highlight color | Base color lightened 45% toward white |
| `--lh-skeleton-radius` | Base radius | `--lh-border-radius-small` |

### Accessibility

- Placeholders are `aria-hidden="true"` and skipped by screen readers
- Container has `aria-busy="true"` + `aria-live="polite"` — the content swap is announced
- The pulse animation is disabled under `prefers-reduced-motion: reduce`
