# Transfer

Two-panel list with checked moving; partitioning and moves are immutable pure core functions. Both panels are `role="listbox"` (APG listbox pattern).

## Basic usage

<DemoBlock title="Basic">
  <LhTransfer :data="items" v-model="source" />
</DemoBlock>

```vue composition
<script setup>
import { ref } from 'vue'
const source = ref(['a'])
const items = [
  { key: 'a', label: 'A' },
  { key: 'b', label: 'B' },
  { key: 'c', label: 'C', disabled: true },
]
</script>

<template>
  <LhTransfer :data="items" v-model="source" />
</template>
```

```vue options
<script>

```

## API

### LhTransfer Props

| Attribute | Description | Type | Default |
| --- | --- | --- | --- |
| data | Full data source | `[LhTransferItem](#type-LhTransferItem)`[] | — |
| modelValue | Source (left) key list | `(string \| number)[]` | `() => []` |
| disabled | Disabled | `boolean` | `false` |
| sx | Quick layout props | `LhSxProps` | — |

### LhTransfer Events

| Event | Description | Callback |
|-------|-------------|----------|
| update:modelValue | Emitted when the target (right) key list changes (use with v-model) | `(keys: Array<string \| number>) => void` |
| change | Emitted after items are moved | `(keys: Array<string \| number>, direction: 'left-to-right' \| 'right-to-left') => void` |

### LhTransferItem

| Field | Description | Type |
| --- | --- | --- |
| key | Unique key | `string \| number` |
| label | Display text | `string` |
| disabled | Disabled (cannot move) | `boolean` |

## Accessibility

- Both panels are `role="listbox"` + `aria-multiselectable`; items are `role="option"` with `aria-selected` / `aria-disabled`
- Move buttons are named real `<button>`s; check-all is a native checkbox with a real `indeterminate` state
- Each panel has its own labelled search box; disabled items are blocked at every layer
