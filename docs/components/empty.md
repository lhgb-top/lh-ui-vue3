## Empty API

### Props

| 属性 | 说明 | 类型 | 默认值 |
| ---- | ---- | ---- | ------ |
| description | 描述文案（未传时取语言包 `empty.description`） | `string` | — |
| image | 自定义图片 URL（替代默认内联插画） | `string` | — |
| sx | sx 快速布局属性 | `SxProps` | — |

### Slots

| 插槽 | 说明 | 默认内容 |
| ---- | ---- | -------- |
| default | 自定义视觉区（替代插画） | 默认水墨插画 |
| description | 自定义描述 | 语言包 `empty.description` |
| actions | 动作区 | — |

### 无障碍

- 容器 `role="status"`：空态出现时自动播报
- 装饰性图片 `alt=""` 对屏读隐藏，语义由描述文案承担
