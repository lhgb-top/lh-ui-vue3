## API

### Props

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| title | 数值标题 | `string` | — |
| value | 统计数值；字符串形式可承载超大数或带符号文本 | `string \| number` | `0` |
| precision | 小数精度 | `number` | `0` |
| separator | 千位分隔符；空串关闭分组 | `string` | `','` |
| prefix | 数值前缀，如货币符号 | `string` | — |
| suffix | 数值后缀，如单位 | `string` | — |
| sx | sx 快速布局属性 | `SxProps` | — |

### Slots

| 插槽名 | 说明 |
| --- | --- |
| title | 自定义标题 |
| prefix | 自定义前缀 |
| suffix | 自定义后缀 |

### 无障碍

- 数值区带 `aria-live="polite"`，`value` 变化时屏幕阅读器温和播报新值
- 标题、前缀、后缀均为普通文本，可直接读取
