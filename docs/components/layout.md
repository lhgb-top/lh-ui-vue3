页面级骨架：`LhLayout` + `LhLayoutHeader` / `LhLayoutAside` / `LhLayoutMain` / `LhLayoutFooter`，全部使用语义标签（`header` / `aside` / `main` / `footer`），landmark 由标签天然获得。

## API

### LhLayout Props

| 属性名 | 说明 | 类型 | 默认值 |
|--------|------|------|--------|
| direction | 排列方向（含 Aside 时自动为 vertical） | `"horizontal" \| "vertical"` | `'horizontal'` |
| sx | sx 快速布局属性 | `SxProps` | — |

### LhLayoutAside Props

| 属性名 | 说明 | 类型 | 默认值 |
|--------|------|------|--------|
| width | 侧栏宽度 | `number \| string` | — |
| ariaLabel | 无障碍名称（landmark 命名） | `string` | — |
| sx | sx 快速布局属性 | `SxProps` | — |

Header / Main / Footer 共用 `sx` 一个 prop。

## 无障碍

- 使用语义标签，`header` / `main` / `footer` / `aside` 直接映射到 landmark role，无需额外 ARIA
- 多个 `aside` 时建议用 `ariaLabel` 区分（如「侧边导航」「相关链接」）
