# TreeSelect 树选择

下拉触发器 + Tree 面板组合。单选返回 `string`，多选（勾选框）返回 `string[]`。

## 基础用法

<DemoBlock title="单选">
  <LhTreeSelect :data="treeData" v-model="treeValue" />
</DemoBlock>

```vue composition
<script setup>
import { ref } from 'vue'
const treeValue = ref(undefined)
const treeData = [
  { key: 'a', label: '前端', children: [
    { key: 'a-1', label: 'Vue' },
    { key: 'a-2', label: 'React' },
  ] },
  { key: 'b', label: '后端' },
]
</script>

<template>
  <LhTreeSelect :data="treeData" v-model="treeValue" />
</template>
```

## API

### LhTreeSelect Props

| 属性名 | 说明 | 类型 | 默认值 |
|--------|------|------|--------|
| data | 树数据 | `[LhTreeNode](#type-LhTreeNode)`[] | — |
| modelValue | 当前值（单选 string / 多选 string[]，受控 v-model） | `string \| string[]` | — |
| multiple | 多选（显示勾选框，值为勾选键数组） | `boolean` | `false` |
| disabled | 禁用 | `boolean` | `false` |
| placeholder | 占位文本 | `string` | — |
| teleported | 面板是否挂到 body（默认 true） | `boolean` | `true` |
| sx | sx 快速布局属性 | `LhSxProps` | — |

### Events

| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| update:modelValue | 选中值变化时触发，配合 v-model 使用（单选为 `string`，多选为 `string[]`） | `(value: string \| string[] \| undefined)` |
| change | 选中变化后触发 | `(value: string \| string[] \| undefined)` |

## 无障碍

- 触发器为真实 `<button>`，`aria-haspopup="tree"` + `aria-expanded` 标注展开态；面板 `role="listbox"`（多选加 `aria-multiselectable`）
- 面板内部完全复用 Tree 的 APG tree pattern 键盘导航
- 点击组件外部或按 Escape 关闭，关闭后焦点归还触发器
