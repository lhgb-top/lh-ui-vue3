## 每页条数与禁用

`v-model:page-size` 受控每页条数，`page-sizes` 自定义条数选项；`disabled` 禁用整个分页。

## Pagination API

### Props

| 属性名 | 说明 | 类型 | 默认值 |
|--------|------|------|--------|
| total | 数据总数（必填） | `number` | — |
| pageSize | 每页条数 | `number` | `10` |
| current | 当前页（`v-model:current`） | `number` | — |
| pageSizes | 每页条数选项 | `number[]` | `() => [10, 20, 30, 40]` |
| showTotal | 是否显示总条数 | `boolean` | `false` |
| showSizeChanger | 是否显示每页条数切换 | `boolean` | `false` |
| showJumper | 是否显示跳页输入 | `boolean` | `false` |
| simple | 紧凑模式 | `boolean` | `false` |
| disabled | 是否禁用 | `boolean` | `false` |
| sx | sx 快速布局属性 | `LhSxProps` | — |

### Events

| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| update:current | 当前页变化（v-model） | `(page: number)` |
| update:pageSize | 每页条数变化（v-model:pageSize） | `(size: number)` |
| change | 页码变化 | `(page: number)` |
| size-change | 每页条数变化 | `(size: number)` |

### 无障碍

- 根元素为 `<nav aria-label="pagination">`
- 当前页按钮自动设置 `aria-current="page"`
- 每个页码按钮、上一页/下一页按钮都有独立的 aria-label（取语言包 `pagination.page` / `prev` / `next`），纯符号「‹」「›」由 `aria-hidden` 隐藏
- 跳页输入框带真实 `<label>`（取语言包 `pagination.goto`）
- 条数切换为原生 `<select>`，带 aria-label（取语言包 `pagination.sizeChangerLabel`）
- 省略号为纯展示 `aria-hidden` 元素，不干扰键盘导航
