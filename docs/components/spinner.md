# Spinner 旋转图形

基础旋转图形，表示进行中的状态。加载遮罩（LhLoading）内部同样由它呈现。

## API

### LhSpinner Props

| 属性名 | 说明 | 类型 | 默认值 |
|--------|------|------|--------|
| size | 尺寸 | `"small" \| "medium" \| "large" \| "mini" \| "x-large"` | `'medium'` |
| color | 旋转颜色（CSS color 值，未传时继承 currentColor） | `string` | — |
| sx | sx 快速布局属性 | `SxProps` | — |

## 无障碍

- 图形为纯装饰，`aria-hidden="true"` 移出无障碍树；进行中状态应由外层容器（如 `role="status"`）承担语义
- 旋转动效尊重 `prefers-reduced-motion`，降级为静态半环
