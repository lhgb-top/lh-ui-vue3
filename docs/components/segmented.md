## API

### LhSegmented Props

| 属性名 | 说明 | 类型 | 默认值 |
|--------|------|------|--------|
| modelValue | 当前值（受控 v-model） | `string \| number` | — |
| options | 选项（字符串快捷写法或对象） | `[LhSegmentedInput](#type-LhSegmentedInput)`[] | — |
| disabled | 整组禁用 | `boolean` | `false` |
| block | 撑满容器 | `boolean` | `false` |
| sx | sx 快速布局属性 | `LhSxProps` | — |

### Events

| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| update:modelValue | 选中项变化时触发，配合 v-model 使用 | `(value: string \| number)` |
| change | 选中项变化时触发（点击与方向键均会触发） | `(value: string \| number)` |

## 无障碍

- `role="radiogroup"` + 选项 `role="radio"` + `aria-checked`
- roving tabindex：方向键移动（跳过禁用项、首尾循环），仅焦点位可 Tab
- 选中底色用 CSS 变量过渡
