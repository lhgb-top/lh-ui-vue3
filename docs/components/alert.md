# Alert 警告提示

页面级静态警告（非命令式，区别于 Message）。语义与 live region 角色联动：`warning`/`danger` 用 `role="alert"` 立即播报，`info`/`success` 用 `role="status"` 温和播报。

## Alert API

### Props

| 属性 | 说明 | 类型 | 默认值 |
| ---- | ---- | ---- | ------ |
| type | 语义类型 | `"info" \| "success" \| "warning" \| "danger"` | `'info'` |
| title | 标题（也可用 title 插槽） | `string` | — |
| closable | 是否可关闭 | `boolean` | `false` |
| showIcon | 是否显示语义图标 | `boolean` | `false` |
| plain | 浅色朴素样式（白底描边） | `boolean` | `false` |
| closeLabel | 关闭按钮的无障碍名称（未传时取语言包 `alert.close`） | `string` | — |
| sx | sx 快速布局属性 | `LhSxProps` | — |

### Events

| 事件 | 说明 | 参数 |
| ---- | ---- | ---- |
| close | 点击关闭按钮后触发 | — |

### Slots

| 插槽 | 说明 |
| ---- | ---- |
| title | 自定义标题 |
| default | 描述内容 |

### 无障碍

- `warning`/`danger` → `role="alert"`（立即播报）；`info`/`success` → `role="status"`（温和播报）
- 关闭按钮为真实 `<button>`，aria-label 取语言包 `alert.close`，`:focus-visible` 焦点环
- 语义色浅底由 `color-mix()` 从语义色派生，自动跟随主题与明暗模式
