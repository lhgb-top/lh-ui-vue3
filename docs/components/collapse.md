## 受控 v-model 与禁用项

`v-model` 受控当前展开面板（单值或数组，随 accordion 模式变化）；`disabled` 禁用单个面板。

<DemoBlock title="受控展开">
  <LhCollapse v-model="activeNames">
    <LhCollapseItem name="a" title="面板 A">受控内容 A</LhCollapseItem>
    <LhCollapseItem name="b" title="面板 B（禁用）" disabled>禁用内容</LhCollapseItem>
    <LhCollapseItem name="c" title="面板 C">受控内容 C</LhCollapseItem>
  </LhCollapse>
</DemoBlock>

```vue composition
<script setup>
import { ref } from 'vue'

const activeNames = ref(['a'])
</script>

<template>
  <LhCollapse v-model="activeNames">
    <LhCollapseItem name="a" title="面板 A">受控内容 A</LhCollapseItem>

    <LhCollapseItem name="c" title="面板 C">受控内容 C</LhCollapseItem>
  </LhCollapse>
```

## API

### LhCollapse Props

| 属性名 | 说明 | 类型 | 默认值 |
|--------|------|------|--------|
| modelValue | 当前激活的面板（受控 v-model，单值或数组） | `LhCollapseKey \| LhCollapseKey[]` | — |
| accordion | 手风琴模式：同时只展开一个 | `boolean` | `false` |
| sx | sx 快速布局属性 | `SxProps` | — |

### Events

| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| update:modelValue | 展开面板变化时触发（受控 v-model） | `(value: LhCollapseKey \| LhCollapseKey[])` |
| change | 展开面板变化时触发（非受控；accordion 下为单值） | `(value: LhCollapseKey \| LhCollapseKey[])` |

### LhCollapseItem Props

| 属性名 | 说明 | 类型 | 默认值 |
|--------|------|------|--------|
| name | 面板唯一标识 | `string \| number` | — |
| title | 标题（也可用 title 插槽） | `string` | — |
| disabled | 禁用 | `boolean` | `false` |
| sx | sx 快速布局属性 | `SxProps` | — |

插槽：`title` 标题、`default` 内容。

## 无障碍

- 对齐 APG accordion pattern：标题为真实 `<button aria-expanded aria-controls>`，内容区 `role="region"` + `aria-labelledby`
- Enter / Space 切换；禁用项原生 `disabled` 移出交互
- 高度过渡用 CSS `grid-template-rows: 0fr/1fr`（无 JS 测高），尊重 `prefers-reduced-motion`
