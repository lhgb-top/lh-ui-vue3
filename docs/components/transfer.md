# Transfer 穿梭框

双栏列表 + 勾选移动，数据分区与移动逻辑在 core 层以不可变方式完成。双栏均为 `role="listbox"`（APG listbox pattern）。

## 基础用法

<DemoBlock title="基础用法">
  <LhTransfer :data="items" v-model="source" />
</DemoBlock>

```vue composition
<script setup>
import { ref } from 'vue'
const source = ref(['a'])
const items = [
  { key: 'a', label: '甲' },
  { key: 'b', label: '乙' },
  { key: 'c', label: '丙', disabled: true },
]
</script>

<template>
  <LhTransfer :data="items" v-model="source" />
</template>
```

## API

### LhTransfer Props

| 属性名 | 说明 | 类型 | 默认值 |
|--------|------|------|--------|
| data | 全量数据 | `[LhTransferItem](#type-LhTransferItem)`[] | — |
| modelValue | 左侧（源）键列表（受控 v-model） | `(string \| number)[]` | `() => []` |
| disabled | 禁用 | `boolean` | `false` |
| sx | sx 快速布局属性 | `LhSxProps` | — |

### Events

| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| update:modelValue | 右侧（目标）键列表变化时触发，配合 v-model 使用 | `(keys: Array<string \| number>)` |
| change | 数据移动完成后触发 | `(keys: Array<string \| number>, direction: 'left-to-right' \| 'right-to-left')` |

### LhTransferItem

| 字段 | 说明 | 类型 |
|------|------|------|
| key | 唯一键 | `string \| number` |
| label | 显示文本 | `string` |
| disabled | 禁用（不可移动） | `boolean` |

## 无障碍

- 双栏均为 `role="listbox"` + `aria-multiselectable`，项为 `role="option"` + `aria-selected` / `aria-disabled`
- 移动按钮为真实 `<button>` 且带命名（移到左侧 / 移到右侧）；全选为原生 checkbox（半选态真实 `indeterminate`）
- 每侧独立的搜索框带 `aria-label`；禁用项全链路拦截（勾选、全选、移动）
