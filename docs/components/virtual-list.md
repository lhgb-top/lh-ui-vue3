# VirtualList 虚拟列表

只渲染可视窗口内的项，支持**定高**与**动态高度**两种模式（动态模式按预计算偏移 + 二分查找定位）。

## 定高

<DemoBlock title="定高">
  <LhVirtualList :data="listData" :height="200" :item-height="40">
    <template #default="{ item, index }">
      <!-- 行高与 item-height 一致：撑满 wrapper 并垂直居中，避免内容溢出叠压 -->
      <div style="height: 100%; box-sizing: border-box; display: flex; align-items: center; padding: 0 12px">
        第 {{ index }} 项 · {{ item }}
      </div>
    </template>
  </LhVirtualList>
</DemoBlock>

```vue composition
<script setup lang="ts">
const listData = Array.from({ length: 1000 }, (_, i) => `项目 ${i + 1}`)
</script>

<template>
  <LhVirtualList :data="listData" :height="200" :item-height="40">
    <template #default="{ item, index }">
      <div>第 {{ index }} 项 · {{ item }}</div>
    </template>
  </LhVirtualList>
</template>
```

```vue options
<script>
export default {
  data() {
    return {
      listData: Array.from({ length: 1000 }, (_, i) => `项目 ${i + 1}`),
    }
  },
}
</script>

<template>
  <LhVirtualList :data="listData" :height="200" :item-height="40">
    <template #default="{ item, index }">
      <div>第 {{ index }} 项 · {{ item }}</div>
    </template>
  </LhVirtualList>
</template>
```

## 动态高度

`itemSize` 返回每项高度（可基于测量结果动态返回）。

<DemoBlock title="动态高度">
  <LhVirtualList :data="listData" :height="200" :item-size="dynamicSize">
    <template #default="{ item, index }">
      <!-- height + padding 双设时必须 border-box，保证实际行高与 itemSize 计量一致 -->
      <div :style="{ height: `${dynamicSize(index)}px`, padding: '10px 12px', boxSizing: 'border-box' }">{{ item }}</div>
    </template>
  </LhVirtualList>
</DemoBlock>

```vue composition
<script setup>
const dynamicSize = (index) => (index % 3 === 0 ? 56 : 36)
</script>

<template>
  <LhVirtualList :data="listData" :height="200" :item-size="dynamicSize">
    <template #default="{ item, index }">{{ item }}</template>
  </LhVirtualList>
</template>
```

```vue options
<script>
export default {
  data() {
    return {
      listData: Array.from({ length: 1000 }, (_, i) => `项目 ${i + 1}`),
    }
  },
  methods: {
    dynamicSize(index) {
      return index % 3 === 0 ? 56 : 36
    },
  },
}
</script>

<template>
  <LhVirtualList :data="listData" :height="200" :item-size="dynamicSize">
    <template #default="{ item, index }">{{ item }}</template>
  </LhVirtualList>
</template>
```

## 预渲染缓冲

`overscan` 指定可视窗口外上下各预渲染多少行，减少快速滚动时的白屏。

## API

### LhVirtualList Props

| 属性名 | 说明 | 类型 | 默认值 |
|--------|------|------|--------|
| data | 数据源（项渲染由 default 插槽负责） | `any[]` | — |
| height | 容器高度（数字为 px） | `string \| number` | — |
| itemHeight | 定高模式的项高 | `number` | — |
| itemSize | 动态高度模式：由调用方返回每项高度 | `(index: number) => number` | — |
| overscan | 过扫描项数 | `number` | `LH_VIRTUAL_OVERSCAN` |
| sx | sx 快速布局属性 | `LhSxProps` | — |

插槽：`default`（作用域 `{ item, index }`）。

## 无障碍

- 容器 `overflow: auto` 可键盘滚动；窗口外的项不在 DOM 中，屏读按需获取（长列表的固有取舍，建议配合搜索/筛选缩小范围）
- 若需完整语义表格请用 Table（其虚拟滚动同样由 core 纯函数驱动）
