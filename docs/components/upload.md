# Upload 上传

原生 `<input type="file">` 驱动 + 拖拽区。**请求由使用方通过 `request` prop 提供**（库零运行时依赖，不内置 HTTP 客户端）。

## 拖拽 + 自定义请求

<DemoBlock title="拖拽上传">
  <LhUpload drag :multiple="true" :request="fakeRequest" />
</DemoBlock>

```vue composition
<script setup>
const fakeRequest = ({ file, onProgress }) =>
  new Promise((resolve) => {
    let percent = 0
    const timer = setInterval(() => {
      percent += 20
      onProgress(percent)
      if (percent >= 100) {
        clearInterval(timer)
        resolve({ url: `https://example.com/${file.name}` })
      }
    }, 200)
  })
</script>

<template>
  <!-- 拖拽上传 -->
  <LhUpload drag :multiple="true" :request="fakeRequest" />
</template>
```

## API

### LhUpload Props

| 属性名 | 说明 | 类型 | 默认值 |
|--------|------|------|--------|
| multiple | 允许多选 | `boolean` | `false` |
| drag | 拖拽上传区 | `boolean` | `false` |
| disabled | 禁用 | `boolean` | `false` |
| accept | 允许的扩展名 / MIME，数组（`['.png', 'image/*']`）或逗号字符串（`'.png,.jpg'`）均可 | `string \| string[]` | `() => []` |
| maxSize | 单个文件大小上限（字节） | `number` | `[LH_UPLOAD_MAX_SIZE](#const-LH_UPLOAD_MAX_SIZE)` |
| maxCount | 数量上限（0 为不限） | `number` | `0` |
| request | 上传请求函数（不传则只做本地选择与校验） | `(options: { file: File; onProgress: (percent: number) => void; }) => Promise<{ url?: string; }>` | — |
| sx | sx 快速布局属性 | `LhSxProps` | — |

### Events

| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| change | 文件列表变化时触发（新增文件、上传结束、移除文件后） | `(files: LhUploadFile[])` |
| success | 单个文件上传成功后触发 | `(file: LhUploadFile)` |
| error | 单个文件上传失败后触发 | `(file: LhUploadFile, reason: string)` |
| remove | 移除文件后触发 | `(uid: string)` |

插槽：`default`（触发区内容）。

### LhUploadRequest

`(options: { file: File; onProgress: (percent: number) => void }) => Promise<{ url?: string }>`

## 无障碍

- 原生 `<input type="file">` 视觉隐藏但保留在无障碍树，`aria-label` 命名
- 触发区 `role="button"` + `tabindex` + Enter/Space 打开文件选择，禁用时移出交互
- 进度条 `role="progressbar"` + `aria-valuenow/min/max`；校验失败 `role="alert"` 播报；每项移除按钮带文件名命名
