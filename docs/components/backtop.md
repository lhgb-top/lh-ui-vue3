# BackTop 返回顶部

滚动超过阈值出现、点击回顶。平滑滚动走原生 `scrollTo({ behavior: 'smooth' })`，`prefers-reduced-motion` 自动降级。

## 滚动停止（scrollend）

`@scrollend` 在滚动停止时抛出当前滚动距离：原生 `scrollend` 事件优先
（Chromium 114+ / Safari 18.2+），旧浏览器自动退回 scroll + 150ms 防抖。常用于锚点联动、数据懒加载。

<DemoBlock title="scrollend 事件">
  <div style="height: 60px" />
  <LhBackTop :right="24" :bottom="160" @scrollend="onScrollEnd" />
  <p class="demo-scrollend-log">最近一次停止位置：{{ lastStop }}</p>
</DemoBlock>

```vue composition
<script setup>
import { ref } from 'vue'

const lastStop = ref('（未滚动）')

function onScrollEnd(scrollTop) {
  lastStop.value = `${scrollTop}px`
}
</script>

<template>
  <LhBackTop :right="24" :bottom="160" @scrollend="onScrollEnd" />
</template>
```

```vue options
<script>
export default {
  data() {
    return { lastStop: '（未滚动）' }
  },
  methods: {
    onScrollEnd(scrollTop) {
      this.lastStop = `${scrollTop}px`
    },
  },
}
</script>

<template>
  <LhBackTop :right="24" :bottom="160" @scrollend="onScrollEnd" />
</template>
```

## API

### LhBackTop Props

| 属性名 | 说明 | 类型 | 默认值 |
|--------|------|------|--------|
| target | 滚动容器（选择器或元素，默认视口） | `string \| HTMLElement` | — |
| visibilityHeight | 滚动多少像素后出现 | `number` | `200` |
| right | 距右侧偏移 px | `number` | `40` |
| bottom | 距底部偏移 px | `number` | `40` |
| smooth | 是否平滑滚动 | `boolean` | `true` |
| sx | sx 快速布局属性 | `LhSxProps` | — |

### Events

| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| click | 点击按钮时触发（随后执行回顶滚动） | `(event: MouseEvent)` |
| scrollend | 滚动停止时触发，携带当前滚动距离 | `(scrollTop: number)` |

插槽：`default`（自定义内容）。

## 无障碍

- 真实 `<button>`，纯图标形态必须命名（语言包 `backtop.label`）
- 出现/消失不进入焦点树冲突（隐藏时 `v-if` 移出）
