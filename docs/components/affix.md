# Affix 固钉

滚动吸顶 / 吸底。用 IntersectionObserver 检测占位越界（无 scroll 节流开销，无 IO 环境自动回退 scroll 监听）。

## 基础用法

<DemoBlock title="吸顶">
  <div class="demo-affix-zone">
    <LhAffix :offset-top="8">
      <div class="demo-affix-bar">吸顶工具条</div>
    </LhAffix>
  </div>
</DemoBlock>

`offset-bottom` 触发吸底（优先于 `offset-top`）；`target` 指定滚动监听容器（默认视口）。

## API

### LhAffix Props

| 属性名 | 说明 | 类型 | 默认值 |
|--------|------|------|--------|
| offsetTop | 距视口顶部多少像素触发吸顶 | `number` | `0` |
| offsetBottom | 距视口底部多少像素触发吸底（优先于 offsetTop） | `number` | `0` |
| target | 滚动监听容器（选择器或元素，默认视口） | `string \| HTMLElement` | — |
| sx | sx 快速布局属性 | `LhSxProps` | — |

### Events

| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| change | 固定态切换时触发（进入或离开吸顶 / 吸底） | `(fixed: boolean)` |

## 无障碍

- 无特殊 role；固定态不影响文档流焦点顺序
- 固定态以占位元素撑高，避免布局跳动
