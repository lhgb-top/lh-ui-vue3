## API

### Props

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| percentage | 进度百分比，超出 [0, 100] 自动钳制 | `number` | `0` |
| type | 形态 | `"line" \| "circle"` | `'line'` |
| status | 状态，`normal` 时达到 100 自动转为 `success` | `"normal" \| "success" \| "warning" \| "exception"` | `'normal'` |
| color | 进度条颜色：字符串或按百分比返回颜色的函数 | `string \| ((percentage: number) => string)` | — |
| strokeWidth | 线条宽度 px（line 为高度，circle 为描边宽度） | `number` | `6` |
| width | 圆形模式画布宽度 px | `number` | `126` |
| showText | 是否展示文字 | `boolean` | `true` |
| format | 自定义文字格式化 | `(percentage: number) => string` | — |
| sx | sx 快速布局属性 | `LhSxProps` | — |

### Slots

| 插槽名 | 说明 | 作用域 |
| --- | --- | --- |
| text | 自定义文字内容 | `{ percentage }` |

### 无障碍

- 根元素带 `role="progressbar"` 与 `aria-valuemin` / `aria-valuemax` / `aria-valuenow`，对齐 WAI-ARIA progressbar 模式
- `aria-valuetext` 同步可见文案：默认为百分比，传 `format` 时播报格式化后的文本（如「42 分」）
- 钳制后的值同步到 `aria-valuenow`，不会出现超出范围的播报
