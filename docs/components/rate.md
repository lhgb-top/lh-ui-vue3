## API

### LhRate Props

| 属性名 | 说明 | 类型 | 默认值 |
|--------|------|------|--------|
| modelValue | 当前评分（受控 v-model） | `number` | `0` |
| max | 星数上限 | `number` | `5` |
| allowHalf | 允许半星 | `boolean` | `false` |
| readonly | 只读（输出星级文本供屏读） | `boolean` | `false` |
| disabled | 禁用 | `boolean` | `false` |
| character | 自定义字符 | `string` | — |
| showScore | 显示分数文本 | `boolean` | `false` |
| scoreTemplate | 分数模板（{n} 占位） | `string` | — |
| sx | sx 快速布局属性 | `SxProps` | — |

### Events

| 事件名 | 说明 | 回调参数 |
|--------|------|----------|
| update:modelValue | 评分变化时触发，配合 v-model 使用 | `(value: number)` |
| change | 评分变化时触发（点击与键盘操作均会触发） | `(value: number)` |

## 无障碍

- 交互态为 `role="radiogroup"`，每颗星真实可聚焦按钮（roving tabindex），方向键调分、Home/End 归零/打满
- 半星模式键盘按 0.5 步进
- 只读态输出 `role="img"` + `aria-label="n 星"` 供屏读
- `:focus-visible` 焦点环
