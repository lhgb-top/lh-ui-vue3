# Skeleton 骨架屏

在内容加载完成前提供占位图。占位块 `aria-hidden` 对屏读隐藏，容器以 `aria-busy` 与 `aria-live` 通知加载状态变化；流光动画尊重 `prefers-reduced-motion`。

## 基础用法

<DemoBlock title="基础用法">
  <LhSkeleton :rows="3" :loading="skeletonLoading" style="max-width: 420px">
    <p>内容加载完成：众鸟高飞尽，孤云独去闲。</p>
  </LhSkeleton>
  <LhButton size="small" style="margin-top: 12px" @click="skeletonLoading = !skeletonLoading">
    {{ skeletonLoading ? '显示内容' : '显示骨架' }}
  </LhButton>
</DemoBlock>

## Skeleton API

### Props

| 属性 | 说明 | 类型 | 默认值 |
| ---- | ---- | ---- | ------ |
| loading | 是否加载态（false 时渲染 default 插槽） | `boolean` | `true` |
| rows | 文本行数 | `number` | `3` |
| avatar | 是否包含圆形头像占位 | `boolean` | `false` |
| animated | 是否开启动画 | `boolean` | `true` |
| sx | sx 快速布局属性 | `SxProps` | — |

### Slots

| 插槽 | 说明 |
| ---- | ---- |
| default | loading 为 false 时渲染的真实内容 |

## SkeletonItem API

### Props

| 属性 | 说明 | 类型 | 默认值 |
| ---- | ---- | ---- | ------ |
| variant | 占位块形状 | `'text' \| 'rect' \| 'circle'` | `'text'` |
| animated | 是否开启动画 | `boolean` | `true` |
| sx | sx 快速布局属性 | `SxProps` | — |

### 主题变量

| 变量 | 说明 | 默认值 |
| ---- | ---- | ------ |
| `--lh-skeleton-bg` | 占位块底色 | 墨色（text-regular）10% 透明混合 |
| `--lh-skeleton-highlight` | 流光高光色 | 底色向白色提亮 45% |
| `--lh-skeleton-radius` | 基础圆角 | `--lh-border-radius-small` |

### 无障碍

- 占位块 `aria-hidden="true"`，不进屏读
- 容器 `aria-busy="true"` + `aria-live="polite"`，加载完成切内容后自动播报
- `prefers-reduced-motion: reduce` 时流光动画自动关闭
